# Gain Direzionale Lab

Web app statica per analisi del gain direzionale da dati Pupil.

## Uso locale
Apri `index.html` in un browser moderno.

## Pubblicazione con GitHub Pages
1. Vai in **Settings → Pages**.
2. In **Build and deployment**, seleziona **Deploy from a branch**.
3. Seleziona branch `main` e cartella `/(root)`, poi salva.

L'app sarà disponibile all'indirizzo:

`https://miemail1234-boop.github.io/neuroapp/`
